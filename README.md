# Homebrew tap for Gone

[Gone](https://getgone.dev) shares a secret exactly once: it's encrypted on your device, opens once from a one-time link, then it's gone. This tap installs `gone`, the command-line client, on macOS and Linux:

```sh
brew install haukened/gone/gone
```

Then send a first secret:

```sh
printf 'hunter2' | gone send --ttl 30m
```

The guide to the CLI is at [getgone.dev/docs/cli](https://getgone.dev/docs/cli/). To run your own Gone server, see [Self-host](https://getgone.dev/docs/self-host/).

## How this tap is updated

`Formula/gone.rb` is generated by [`scripts/homebrew-formula.sh`](https://github.com/haukened/gone/blob/main/scripts/homebrew-formula.sh) in [haukened/gone](https://github.com/haukened/gone), and the release workflow there pushes it here for every stable release. It installs the release's prebuilt archives, checked against the release's `SHA256SUMS`. To check a release's provenance, see [Verify a release](https://getgone.dev/docs/verify/).

Please report problems in [haukened/gone](https://github.com/haukened/gone/issues), not here.
